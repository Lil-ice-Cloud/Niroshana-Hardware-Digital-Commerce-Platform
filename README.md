# Niroshana-Hardware-Digital-Commerce-Platform

🛒 E-commerce platform for Niroshana Hardware Stores in Hingurakgoda, Sri Lanka.

This project is built with Next.js and was originally bootstrapped with `create-next-app`.

## Getting Started

First, run the development server:

```bash
npm run dev
# or
yarn dev
# or
pnpm dev
# or
bun dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

You can start editing the page by modifying `app/page.tsx`. The page auto-updates as you edit the file.
